# Aturan Kerja Agen (AGENTS.md)

1. **Baca PRD:** Selalu baca dan pahami `docs/PRD.md` sebelum mengerjakan tugas atau fitur apa pun.
2. **Satu Fitur Per Tugas:** Kerjakan satu fitur per tugas dan jangan mengubah file di luar cakupan fitur tersebut.
3. **Kode Lengkap:** Jangan menulis placeholder (`// TODO`, `// implement here`) atau kode terpotong. Tulis implementasi penuh yang dapat dijalankan.
4. **Update Checklist:** Setiap kali sebuah fitur MVP selesai dikerjakan dan diverifikasi, centang checklist yang bersesuaian di `README.md`.
5. **Kepatuhan Arsitektur:** Pertahankan struktur feature-first (`lib/features/...`) dan gunakan repository layer (mock / API).
